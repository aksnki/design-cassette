# Design Cassette — Website

A responsive static website for **Design Cassette — Creative Design & Digital Solutions**.

## Included
- Landing / Hero
- About section
- 7 service cards with relevant creative photography
- Process section
- Pricing / packages
- WhatsApp enquiry form
- Responsive mobile navigation
- Scroll reveal animations
- Design Cassette black + warm gold visual system
- Local logo asset

## Files
- `index.html` — website structure/content
- `styles.css` — responsive styling and animations
- `script.js` — navigation, reveal animations and WhatsApp form
- `assets/design-cassette-logo.png` — supplied logo

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
This is a plain HTML/CSS/JS site, so it can be deployed directly to GitHub Pages, Netlify, Vercel or any standard static hosting.

## Customization
- Edit service/pricing copy in `index.html`.
- Replace the Unsplash image URLs in the service cards with your own portfolio images when available.
- Update the WhatsApp number in `index.html` and `script.js` if the business contact changes.
